Open eD2k links with a click

eD2k Link Fixer changes | to %7C in eD2k links on web pages. Both spellings mean the same thing to compatible eD2k apps; the encoded spelling lets Chrome pass the link to your computer.

Get started

  1. Install aMule or another compatible eD2k app and register it as your computer’s handler for eD2k links. In recent aMule builds, look for the eD2k link-handler option in Preferences → General. Older installations may require OS-specific setup.
  2. Refresh any web pages that were open when you installed the extension.
  3. Click an eD2k link. Accept Chrome’s request to open your app if prompted.

If a link does not open

  • Open the app yourself and confirm it is configured to handle eD2k links. This extension does not install or register the app.
  • In Chrome’s extension details, check that this extension has site access to the page. Then refresh it.
  • If you previously refused Chrome’s external-app prompt, try clicking the link again and allow the app to open.
  • This extension handles actual links on HTTP and HTTPS pages, including matching frames. It cannot run on Chrome’s settings pages, the Chrome Web Store or other restricted pages. Local files are outside its scope.
  • Plain text, links constructed entirely by a website’s JavaScript, and some custom link controls may need to be copied into your app instead.

Privacy & permissions

All processing happens in your browser. The extension makes no network requests, collects no analytics, stores no browsing data and has no background service or native helper.

Chrome requests access to HTTP and HTTPS sites because eD2k links can appear on any website. The script reads link addresses and only rewrites pipe characters in eD2k links. You can restrict its site access in Chrome’s extension details.

Coverage

Linux is the validated operating system. Windows and macOS require a working OS handler and have not been tested. The extension preserves Chrome’s user-gesture and permission requirements and does not queue bulk downloads.

Remove or update

Remove it from Chrome’s Extensions page. For a manual update, replace the extracted extension files, press Reload on that page and refresh your web pages. Keep the extension folder in a permanent location while using it.
